# 3. 리그

## 리그 구조

✅ 6부제다. 내 팀은 6부 시민 아마추어에서 시작한다.

| 부 | 리그 | 성격 |
|---|---|---|
| 1부 | **프로** | 최상위. KBO 1군 수준 |
| 2부 | **세미프로** | 퓨처스 리그 수준 |
| 3부 | **아마추어** | 실업·대학 야구 수준 |
| 4부 | **시민 프로** | 시민 리그 최상위 |
| 5부 | **시민 세미프로** | |
| 6부 | **시민 아마추어** | 시작 리그. 동네 사회인 야구 수준 |

💡 리그마다 10팀 (KBO와 같은 수). 내 팀 1 + AI 팀 9.

✅ CPU 팀은 리그별 강도 범위 안에서 내 팀 수준에 적당히 맞춰 준다. 리그가 올라갈수록 범위가 높아진다 (예: 6부 20~40 → 1부 70~92). 자세한 내용은 → [세계 시뮬레이션](06-world-simulation.md#cpu-팀-맞춰주기)

✅ 6개 리그가 모두 같은 속도로 진행된다. 내가 경기를 한 번 하면 모든 리그가 한 라운드씩 진행된다.

## 일정

✅ 같은 리그의 모든 팀과 홈 2경기, 원정 2경기씩 치른다.

- 10팀이면 상대 9팀 × 4경기 = **팀당 36경기**, 한 시즌은 **36라운드**.
- 💡 일정은 더블 라운드 로빈 2번으로 만든다. 1~18라운드에서 모든 팀과 홈 1번·원정 1번, 19~36라운드에서 한 번 더.
- 💡 같은 상대와 연속으로 붙지 않게 섞는다.

## 순위

💡 KBO 방식:
1. 승률 (무승부 제외)
2. 동률이면 상대 전적
3. 그래도 같으면 다득점

## 승강 플레이오프

✅ 인지도가 충분하면 승강 플레이오프를 신청할 수 있다.
✅ 진출 여부는 정규시즌이 모두 끝난 뒤 순위로 정한다.

### 신청 조건

💡 시즌 중 **리그** 탭에서 신청한다. 신청하려면 리그별 인지도 기준을 넘어야 한다.

| 현재 리그 → 목표 리그 | 필요 인지도 (💡) |
|---|---|
| 6부 시민 아마추어 → 5부 시민 세미프로 | 100 |
| 5부 → 4부 시민 프로 | 300 |
| 4부 → 3부 아마추어 | 700 |
| 3부 → 2부 세미프로 | 1,500 |
| 2부 → 1부 프로 | 3,000 |

- 신청 마감은 💡 정규시즌 27라운드(3/4 지점)까지. 신청한 뒤에 인지도가 기준 아래로 떨어져도 신청은 유지된다.
- 💡 신청비가 있다 (리그가 높을수록 비쌈). 자금 사용처가 하나 더 생긴다.
- AI 팀은 항상 신청한 것으로 본다.

❓ 3부 아마추어로 올라갈 때(시민 → 일반 리그) 특별한 조건을 더 둘지. 예) 경기장 Lv3 이상, 프로 계약 선수 일정 수 이상

### 진출과 방식

💡 정규시즌이 끝나면 하위 리그 상위팀과 상위 리그 하위팀이 맞붙는다.

| 대진 | 방식 |
|---|---|
| 하위 리그 **1위** vs 상위 리그 **10위** | 3전 2선승, 상위 리그 팀 홈에서 1·3차전 |
| 하위 리그 **2위** vs 상위 리그 **9위** | 3전 2선승, 상위 리그 팀 홈에서 1·3차전 |

- 이긴 팀이 다음 시즌 상위 리그에서 뛰고, 진 팀은 하위 리그로 간다.
- 내 팀이 1~2위인데 신청하지 않았거나 인지도가 모자라면 그 자리는 3위 팀이 이어받는다.
- 승강 플레이오프 경기도 1시간마다 한 경기씩 진행한다.
- 💡 승격하면 큰 인지도 보너스와 "승격 지원금"을 받는다.

### 강등

❓ 강등 규칙을 정해야 한다.
- A안: 위 플레이오프에서 지는 경우에만 강등된다 (상위 리그 9·10위가 지면 내려감)
- B안: A안 + 10위는 플레이오프 없이 자동 강등, 9위만 플레이오프
- 💡 A안 추천. 열심히 올라간 리그에서 한 번에 떨어지는 부담을 줄인다.
- 6부 시민 아마추어는 최하위 리그라 강등이 없다.

## 시즌 흐름

```
정규시즌 36라운드 → 시상식 → 승강 플레이오프 → 오프시즌 → 다음 시즌
```

💡 오프시즌 (경기 1회분 시간, 1시간):
- 선수 성장과 노화 반영, 은퇴
- 자유계약(FA) 시장 열림 → [선수 영입](05-player-recruitment.md)
- 신인 드래프트 (3부 이상)
- 새 시즌 일정 생성

## 상대 팀

✅ 상대 팀과 리그는 KBO를 기준으로 만든다.

✅ 상대 팀은 모두 **가상 구단**이다. 리그 운영 방식(10팀, 일정, 순위, 규칙)은 KBO를 따른다.

✅ 1부 프로 리그 10팀은 실제 KBO 구단의 연고지와 애칭을 **우리말로 옮긴 이름**을 쓴다. 야구팬이 보면 바로 알아보고 웃을 수 있는 이름이 목표다.

| 연고지 | 가상 구단 | 모티브 |
|---|---|---|
| 광주 | **광주 호랑이** | 타이거즈 |
| 대구 | **대구 사자** | 라이온즈 |
| 부산 | **부산 거인** | 자이언츠 |
| 대전 | **대전 독수리** | 이글스 |
| 서울 잠실 | **잠실 곰** | 베어스 |
| 서울 잠실 | **서울 쌍둥이** | 트윈스 |
| 서울 고척 | **고척 영웅** | 히어로즈 |
| 인천 | **인천 상륙단** | 랜더스 |
| 수원 | **수원 마법사** | 위즈 |
| 창원 | **창원 공룡** | 다이노스 |

- 게임 시작 시 1부에 있는 팀들이다. 시즌이 지나면 강등될 수도 있다.

### 지키는 선

애칭을 우리말로 옮기는 것 말고는 실제 구단과 겹치지 않게 한다. 구단명과 엠블럼은 등록 상표이고, 실제 선수 이름은 퍼블리시티권 문제가 있기 때문이다.

| 쓰지 않는 것 | 대신 |
|---|---|
| 영문 애칭 그대로 (타이거즈, 라이온즈 등) | 우리말로 옮긴 애칭 |
| 모기업·스폰서 이름 (실제 기업명 전부) | 연고지 이름만 |
| 실제 엠블럼, 유니폼 색 조합 | 직접 디자인한 엠블럼과 색 |
| 실제 선수·감독 이름 | 자동 생성 이름. 💡 KBO 현역·주요 은퇴 선수 이름은 생성기에서 걸러낸다 |

- README와 앱 정보 화면에 "KBO 및 각 구단과 무관한 비공식 팬 프로젝트" 면책 문구를 넣는다.
- 💡 설정에서 모든 팀 이름을 바꿀 수 있게 한다 (Football Manager처럼). 문제가 생기면 기본 이름만 바꾸면 된다.

### 하위 리그 팀

💡 하위 리그 AI 팀은 지역 시민 구단, 대학, 실업팀 느낌의 이름을 자동으로 만든다 (예: "청주 시민 야구단", "한빛대학교", "동해 철강 야구부"). 실제 학교·기업 이름은 쓰지 않는다.

💡 AI 팀도 시즌마다 선수가 성장하고 바뀌며, 승격·강등된다. 리그 구성이 해마다 조금씩 달라진다.
