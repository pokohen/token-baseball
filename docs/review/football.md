# 축구 검토

[검토 방법과 요약](README.md) · 관련 문서: [축구 모드](../07-football.md), [리그](../03-league.md), [선수 모드](../08-player-mode.md)

**결론**: 득점 수준은 모든 리그에서 현실적이었다. 고칠 것은 승강 구조, 홈 승률·퇴장·페널티킥 빈도, 출장 정지가 없는 것, 선수 모드의 공격수 체력·훈련 속도·평점이었다. 게임이 깨지는 수준의 문제는 없었다.

## 측정값

검토 때 잰 값(리그당 2,160경기 × 스냅샷 5개)과, 고친 뒤 다시 잰 값(리그당 180경기)이다. "실제"는 대략의 범위다.

| 항목 (한 경기) | 고치기 전 | 고친 뒤 | 실제 축구 |
|---|---|---|---|
| 골 | 2.6~3.1 | 2.6~2.9 | 2.5~3.2 |
| 홈 승 / 무 / 원정 승 (1부) | 52~54 / 22~23 / 23~24 % | 44 / 22 / 33 % | 41~46 / 24~27 / 29~33 % |
| 홈 승 / 무 / 원정 승 (6부) | 44~46 / 23~26 / 28~32 % | 40 / 26 / 33 % | 같음 |
| 퇴장 | 0.23~0.30 | 0.07~0.12 | 0.1~0.2 |
| 경고 | 3.2~3.5 | 2.8~3.1 | 3.3~4.5 |
| 페널티킥 | 0.51~0.59 | 절반으로 줄임 (다시 재지 않음) | 0.25~0.35 |
| 코너킥 | 7.3~7.9 | 9.5~10.1 | 약 10 |
| 슈팅 | 22.8~24.8 | 23.0~24.4 | 24~27 |
| 7골 이상 경기 | 2~3% | — | 2~3% |
| 0:0 | 4.4~7.7% | — | 6~8% |

**6:4 같은 점수에 대해**: 리그별 평균 득점은 차이가 없다. 10골 이상 경기의 비율(0.08%)은 평균 2.85골에서 나올 수 있는 값(약 0.1%)과 같다. 세계 전체가 한 시즌에 1,080경기를 치르므로 어딘가에서 시즌에 한 번쯤 나오는 점수이고, 6부의 문제가 아니다.

## 승강

**지적**: 상위 9위와 하위 2위가 맞붙는 승강전은 독일·K리그 방식이다. 잉글랜드는 하위 몇 팀이 자동 강등되고, 승격 플레이오프는 하위 리그 팀끼리만 한다. 3전 2선승은 축구에 없다. 신청 절차도 없고, 대신 구장 등급 심사가 있다.

**반영**: 잉글랜드 방식으로 바꿨다. 자세한 규칙은 → [리그](../03-league.md#축구-잉글랜드-방식)

| 항목 | 잉글랜드 (챔피언십·리그 원) | 이 게임 (10팀 리그) |
|---|---|---|
| 자동 승격 | 1~2위 | 1위 |
| 승격 플레이오프 | 3~6위, 한 팀 승격 | 2~5위, 한 팀 승격 |
| 준결승 | 홈·원정 두 경기 합산, 순위가 낮은 팀이 1차전 홈, 원정 다득점 없음 | 같다 |
| 결승 | 중립 구장 단판, 연장 → 승부차기 | 같다 |
| 강등 | 하위 3팀 | 9위와 10위 |
| 승격 조건 | 구장 등급 심사 | 경기장 레벨 |

보류한 것:
- **재정 위기 때 승점 삭감**: 잉글랜드에는 있지만 지금의 파산 유예 규칙과 겹쳐서 넣지 않았다.
- **순위 동률의 마지막 기준**: 승점·골득실·다득점·상대 전적까지 같으면 구단 번호 순이다. 다승 → 추첨으로 바꾸라는 권고는 드문 경우라 보류했다.

## 지적 사항과 처리

| # | 지적 | 처리 |
|---|---|---|
| 1 | 승강 구조가 잉글랜드식이 아니다 | **반영** (위) |
| 2 | 출장 정지가 없고, 경고 누적 퇴장이 실제의 두 배다 | **반영**: 퇴장하면 다음 리그 1경기, 시즌 경고 5장마다 1경기 정지. 이미 경고가 있는 선수는 두 번째 경고를 받을 확률이 절반. 곧바로 퇴장을 2경기로 하라는 권고는 넣지 않았다 (1경기로 통일) |
| 3 | 홈 이점이 상위 리그에서 과하다 (1부 홈 승률 52~54%) | **반영**: 홈 보정을 줄였다 |
| 4 | 페널티킥이 실제의 두 배다 | **반영**: 절반으로 줄이고, 줄어든 득점은 유효 슈팅의 득점률을 조금 올려 메웠다 |
| 5 | 공격수는 주전이어도 65분만 뛴다 (체력이 능력에 들어가지 않아 낮게 만들어지고, 선수 모드에서는 훈련할 수도 없다) | **반영**: 공격수의 능력에 체력을 넣었다. 선수 모드에서도 훈련할 수 있다 |
| 6 | 선수 모드의 토큰 훈련이 너무 빠르고, 골키퍼가 1.5배 유리하다 (골키핑이 능력의 70%라 한 번에 +0.7) | **반영**: 어떤 훈련이든 능력이 0.25 오른다. 훈련으로는 지금 리그 강도의 위쪽 끝 +5까지만 오른다 |
| 7 | 평점에 들어가는 태클·걷어내기·전진 기록이 그 자리 선수 중에서 무작위로 정해진다. 수비나 패스를 훈련해도 평점이 직접 오르지 않는다 | **반영**: 선수 모드에서는 그 능력치가 좋은 선수가 더 자주 그 일을 한다 |
| 7 | 플레이 스타일이 팀에 대가 없이 기록만 옮긴다 | **반영**: 욕심내기는 내 슈팅의 정확도가 떨어진다. 연계는 도움 하나의 평점이 0.6 → 0.8 |
| 8 | 감독 신뢰가 훈련만으로 찬다 (훈련할 때마다 +0.5) | **반영**: +0.1로 줄였다. 30분도 못 뛴 교체 출전은 기준을 따로 둔다 (6.5 이상 +0.5, 5.7 미만 −0.5) |
| 8 | 능력이 모자란 채 윗 리그에 가면 계속 교체로만 나와 신뢰가 0까지 내려간다 | **일부 반영**: 윗 리그의 "유망주" 제안은 능력이 그 리그 최저 수준 −8 이상일 때만 온다. 제안 화면에 "주전과 능력 차"를 보여 주라는 권고는 보류했다 (커리어 탭의 주전 경쟁 카드로 볼 수 있다) |
| 9 | 나이 곡선이 야구 것 그대로다 | **반영**: 필드 선수는 29세에 성장이 멈추고 30세부터 스피드·체력이 내려간다. 골키퍼는 32세까지 크고 35세부터 하락, 은퇴도 3년 늦다 |
| 10 | 드래프트는 축구에 없다 | **반영**: 유소년 승급으로 바꿨다 |
| 10 | 이적 기간이 KBO 트레이드 마감 방식이다 | **반영**: 여름(오프시즌 + 1~3라운드)과 겨울(17~20라운드) |
| 10 | 무소속 선수는 이적 기간 밖에도 계약한다 | **반영** |
| 10 | 연봉이 시즌마다 자동으로 오른다 (KBO 방식) | **반영**: 축구는 계약 기간 동안 그대로다 |
| 11 | 종료 직전에 주어진 페널티킥이 사라진다 | **반영** |
| 11 | 10명이 됐을 때의 불이익이 약하다 | **반영**: 두 배로 올렸다 |
| 11 | 코너킥이 적다 | **반영** |
| 11 | 교체가 6분마다 한 명씩이라 다섯 번 끊긴다 (규칙은 세 번에 나눠 넣는다) | **보류**: 결과에 영향이 작고 엔진을 많이 고쳐야 한다 |
| 11 | 로스터 전원이 벤치에 앉는다 (실제는 9명) | **보류**: 선수단이 20~28명이라 영향이 작다 |
| 11 | MVP가 골 + 도움으로만 정해져 늘 공격수다 | **보류**: 모든 선수에게 평점을 남기게 되면 평균 평점으로 바꾼다 |

## 그대로 둬도 된다고 본 것

- 경기 시간 20초 단위, 경기장을 세 구역으로 나눈 모델, 오프사이드가 고정 확률인 것, 부상이 없는 것.
- 10팀이 네 번씩 붙는 36라운드 (스코틀랜드 리그가 이 방식이라 축구로도 자연스럽다), 승점 3-1-0.
- 추가시간, 승부차기 순서, 선수단 20·24·28명, 계약 1~3시즌, 외국인 선수 3명.
- 선수 모드에서 16세에 6부에서 시작하는 것, 선발이 아니면 반드시 교체로 나오는 것, 주전이 아닌 골키퍼가 네 경기에 한 번 선발인 것.
- 성장 공식 자체.
