# 야구 검토

[검토 방법과 요약](README.md) · 관련 문서: [경기](../02-match.md), [리그](../03-league.md), [야구 선수 모드](../09-baseball-player-mode.md)

**결론**: 가장 큰 문제는 홈런 공식이었다. 능력치가 높은 리그일수록 홈런이 쏟아져 1부 선발 투수의 평균자책점 중앙값이 5.5를 넘었다. 승강 구조는 36경기를 유지해도 되고, 와일드카드와 로테이션 규칙을 더하면 된다는 판단이었다.

## 측정값

검토 때 잰 값과, 고친 뒤 다시 잰 값이다 (팀당 한 경기 기준, 리그당 180경기). "실제"는 KBO의 대략적인 범위다.

| 지표 | 1부 전 → 후 | 6부 전 → 후 | 실제 |
|---|---|---|---|
| 득점 | 5.5 → 4.2 | 4.1~4.2 → 4.6 | 4.4~5.4 |
| 홈런 | 2.4~2.6 → 0.9 | 0.6 → 0.9 | 0.7~1.0 |
| 타율 | .254~.258 → .248 | .260~.268 → .266 | .260~.277 |
| 출루율 | .306~.311 → .320 | .306~.315 → .322 | .335~.352 |
| 장타율 | .511~.523 → .387 | .365~.377 → .394 | .375~.420 |
| 볼넷 비율 | 7.0~7.3 → 9.5 % | 6.5 → 7.5 % | 9~10 % |
| 도루 | 0.7~0.8 → 0.4 | 0.00 → 0.2 | 0.6~0.9 |
| 선발 평균자책점 | 5.4~5.7 → 4.2 | 3.9~4.3 → 4.6 | 4.1~4.9 |
| 팀당 투수 수 | 2.9~3.0 → 3.3 | 2.7~2.9 → 2.9 | 4.5~5 |

고친 뒤의 값에서 아직 실제와 어긋나는 것: 출루율이 조금 낮고, 도루가 적고, 경기당 투수 수가 적다. 2부는 득점이 3.8로 다른 리그보다 낮게 나왔다 (180경기 표본의 흔들림인지는 가리지 못했다).

## 승강

실제 프로야구에는 승강제가 없어서 이 게임이 직접 만든 방식이다. 검토자는 300시즌을 반복해 36경기 시즌이 얼마나 믿을 만한지 쟀다.

| | 1부 36경기 | 1부 72경기 | 6부 36경기 | 6부 72경기 |
|---|---|---|---|---|
| 실제 꼴찌가 10위를 한다 | 47% | 57% | 45% | 54% |
| 실제 꼴찌가 9·10위 안에 든다 | 75% | 83% | 75% | 86% |
| 실제 1위가 2위 안에 든다 | 81% | 90% | 66% | 77% |
| 실제 1위가 3위 안에 든다 | 95% | 99% | 84% | 92% |
| 승강이 걸린 경계에서 승률이 같다 | 13% | 5% | 14~15% | 5% |

**판단**
- **36경기는 유지해도 된다.** 두 배로 늘려도 정확도는 10%p만 오르는데 실시간은 두 배가 된다. 이 게임은 구단 사이의 실력 차가 실제 리그보다 커서 36경기로도 가려진다.
- **10팀이 네 번씩 붙는 일정**은 균형이 맞다.
- **플레이오프를 5전제로 늘리는 이득은 3~5%p**뿐이다. 길이보다 "누가 나가느냐"와 "누가 던지느냐"가 더 중요하다.
- **신청 + 인지도 조건은 남겨도 된다.** 승강제가 있던 네덜란드 리그와 독일 리그도 승격하려는 팀이 요건을 갖추고 의사를 밝혀야 했다.

| 권고 | 처리 |
|---|---|
| 정규시즌 36라운드 유지 | **유지** |
| 하위 리그 2위와 3위의 **승격 와일드카드** (2위 홈, 2위는 1승·3위는 2연승) | **반영**. 6부에서 실제 1위가 승격 길에서 밀려나는 시즌이 34% → 16%로 줄어든다 |
| 승강 플레이오프 3전 2선승 유지 | **유지** |
| 대진이 정해지면 선발 투수의 휴식을 채워 **1차전을 에이스 대결**로 | **반영**. 예전에는 36라운드에 누가 던졌느냐로 1차전 선발이 정해졌다 |
| CPU끼리의 시리즈에서 같은 선발이 1·2·3차전에 연달아 나오는 문제 | **반영** |
| 홈 보정 줄이기 (상위 팀이 플레이오프 2경기를 홈에서 치른다) | **반영** |
| 승강이 걸린 경계에서 승률이 같으면 **순위 결정전** 단판 | **보류**. 한 시즌에 13~15%쯤 생기는 경우를 위해 단계가 하나 더 늘어난다. 지금은 상대 전적 → 다득점으로 가린다 |
| 동률 기준을 다득점 대신 득실차로 | **보류** |

자세한 규칙은 → [리그](../03-league.md#야구-와일드카드와-승강-플레이오프)

## 지적 사항과 처리

| # | 지적 | 처리 |
|---|---|---|
| 1 | 홈런이 타자 파워에만 지수로 반응한다. 양 팀 능력치가 85면 팀당 2.3개가 나온다. 선수 모드에서 파워만 올리면 OPS 1.168이 된다 | **반영**: 파워와 구위의 차이로 정한다 |
| 2 | 볼넷과 출루율이 모든 리그에서 낮다 | **반영**: 볼넷을 늘렸다. 출루율은 아직 조금 낮다 |
| 3 | 가장 좋은 불펜 투수가 매 경기 나온다 (36경기 중 36경기, 시즌 투구 수가 선발보다 많다). 나머지 불펜은 나오지 않는다 | **일부 반영**: 28구에서 교체하고, 직전 경기에 25구 넘게 던졌거나 연투한 불펜은 다음 경기에 맨 뒤로 보낸다. 시민 리그의 불펜을 2명 → 3명으로 늘리라는 권고는 보류했다 (시작 선수단 구성이 바뀐다) |
| 4 | 다음 경기 선발을 지정할 때 휴식을 검사하지 않아 에이스를 매 경기 낼 수 있다 | **반영** |
| 5 | 도루가 4~6부에 없다 (주력이 50을 넘어야 뛴다) | **반영**: 주자의 발과 포수 어깨의 차이로 뛴다 |
| 6 | 홈 보정이 경기장 레벨이 높으면 과하다 (같은 전력끼리 홈 승률 58.8%) | **반영**: 절반으로 줄였다 |
| 7 | 팀 훈련 방침에서 투수 비중을 최대로 하면 팀 전체 성장량이 69% 늘어난다 | **반영**: 배율에 한도를 뒀다 |
| 8-1 | 선수 모드에서 투수·지명타자는 능력치가 4개, 야수는 6개라 야수가 1.5배 느리게 큰다 | **반영**: 어떤 훈련이든 능력이 0.25 오른다 |
| 8-2 | 토큰을 안 쓴 선발 투수가 능력 40~56으로 1부에 가서 계속 선발로 나온다 | **일부 반영**: 윗 리그의 유망주 제안에 능력 조건을 달았다. 신뢰가 낮으면 선발 차례를 거르라는 권고는 보류했다 ("내 선수가 나오지 않는 경기"를 늘리지 않으려는 것) |
| 8-3 | 훈련할 때마다 감독 신뢰 +0.5는 공짜다 | **반영**: +0.1 |
| 8-4 | 평점 기준이 역할마다 다르다 | **반영**: 타자 기준을 6.0 → 6.1, 선발을 6.3 → 6.2로 맞췄다. 타자 평점에 수비가 없다는 지적은 보류했다 |
| 8-6 | 선발 투수가 5경기 중 4경기를 구경만 한다 | **반영**: 등판하지 않는 날은 훈련을 한 번 더 한다. "매 경기 등판"은 기록이 망가지니 하지 말라는 의견이었다 |
| 9 | 제구가 볼넷에만 쓰여, 능력에 들어가는 비중(28%)만큼 값을 못 한다. 같은 능력의 구위 투수는 평균자책점 2.62, 제구 투수는 4.60 | **반영**: 제구가 좋으면 홈런과 직선타를 덜 맞는다 |
| 9 | 포수의 수비 능력치가 경기에 쓰이지 않는다 | **보류** |
| 10 | 선발이 5이닝을 못 채워도 승리 투수가 된다 (6부 선발승의 23%) | **반영**. 선수 모드의 선발 시즌 목표도 낮췄다 (시민 리그 4승 → 3승) |
| 10 | 자책점 판정이 단순하다 (실책 뒤의 실점 처리) | **보류** |
| 10 | 끝내기 안타 때 결승점 뒤의 주자 득점까지 올라간다 | **보류** |
| 10 | 세이브 요건이 단순하다 | **보류** |
| 10 | MVP가 늘 OPS 1위 타자이고, 규정 이닝이 낮아 불펜이 평균자책점 1위 후보가 된다 | **보류** |
| 11 | 나이 곡선이 능력치 구분 없이 같다 | **반영**: 31~33세에는 주력·수비·구위·체력만 조금 내려가고 선구안·제구는 조금 는다 |

## 그대로 둬도 된다고 본 것

- 대타·대수비·대주자가 없는 것 (지명타자제에 감독 개입도 없는 게임이다), 좌우 상성이 없는 것, 희생번트·사구·고의사구·견제·보크가 없는 것.
- 연장 11회 무승부, 플레이오프의 끝장 승부, 시민 리그의 콜드게임 (4~6부 경기의 10~19%가 콜드게임으로 끝난다).
- 선발 휴식 (시민 리그 2경기, 1~3부 4경기), 로스터 28·22·18명.
- 16세 선발 투수의 투구량: 시민 리그에서 한 시즌 12~14경기, 58~77이닝, 경기당 70~85구에 2경기 휴식이다. 무리한 양이 아니다.
- 마무리 투수를 선수 모드에서 고를 수 없게 한 것 (1~3부 마무리는 36경기 중 9~10경기에만 나온다).
- "선발은 팀 경기 수로 쉰다"는 방식.
