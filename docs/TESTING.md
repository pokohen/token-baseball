# 테스트 안내

자동 테스트가 지키는 것과, 사람이 직접 눌러 봐야 하는 것을 나눠 적는다.
아래 수동 항목은 **아직 아무도 확인하지 않은 것**이다. 확인하면 `[x]`로 바꾼다.

## 준비

진짜 저장 파일을 건드리지 않게 저장 위치를 바꿔 실행한다. 선수 모드와 축구 구단의 저장 파일도 같은 폴더에 생긴다.

```sh
mkdir -p /tmp/tb-test
TOKEN_BASEBALL_SAVE=/tmp/tb-test/save.json swift run TokenBaseball
```

처음부터 다시 하려면 `/tmp/tb-test` 폴더를 지운다.

## 자동 테스트

```sh
swift test                                    # 전체 (5~6분)
swift test --filter Career                    # 선수 모드만 (2분쯤)
swift test --filter UsageReader               # 토큰 읽기만
TB_STRESS=1 swift test --filter StressTests   # 여러 시드 장기 시뮬레이션
```

앱 흐름 자가 점검도 있다. 화면 없이 앱 상태를 직접 몰아서 네 가지 모드의 만들기, 훈련, 경기, 모드 전환, 다시 켜기(경기 도중 포함)가 실제 저장 파일과 함께 돌아가는지 본다. 지정한 폴더는 비워지므로 빈 폴더를 준다.

```sh
swift build && TOKEN_BASEBALL_SELFTEST=/tmp/tb-selftest .build/debug/TokenBaseball
```

자동 테스트가 지키는 것:

- 야구 구단 모드가 같은 시드에서 늘 똑같이 흘러간다 (지문 비교). 예전 엔진으로 만든 저장 파일도 지금 코드로 읽어 이어 간다
- 선수 모드 (야구·축구): 선수 만들기, 출전 규칙, 평점, 훈련 비용과 횟수 제한, 리그 한도, 한계 돌파, 이적·재계약·무소속, 은퇴와 새 선수, 저장 칸, 세 시즌 연속 진행
- 승강: 야구의 와일드카드와 승강 플레이오프, 축구의 2팀 승격·2팀 강등과 승격 플레이오프(두 경기 합산, 중립 결승), 구장 등급
- 전문가 검토 뒤의 규칙: 득점 환경(야구 득점·홈런·볼넷, 축구 득점·홈 승률·퇴장), 선발승 5이닝, 선발 휴식, 불펜 휴식, 출장 정지, 축구 이적 기간, 나이 곡선
- 토큰 읽기: 네 가지 도구의 기록 형식, 중복 제거, 깨진 줄 건너뛰기

자동 테스트가 **지키지 못하는 것**: 화면, 버튼과 입력 칸을 눌렀을 때의 동작, 실제 토큰 로그, 실시간 중계의 속도, 알림. 아래에서 직접 본다.

## 꼭 확인할 것

### 1. 선수 만들기 화면 (가장 먼저)

화면 그림으로 생김새는 확인했지만, 한 번도 직접 눌러 보지 못한 부분이다.

- [ ] 처음 화면에서 "야구 선수" 카드를 고르고 "다음"을 누르면 선수 만들기 화면이 나온다
- [ ] 이름을 비우고 "커리어 시작"을 누르면 "선수 이름을 입력해 주세요"가 나오고 넘어가지 않는다
- [ ] 타자 ↔ 투수를 바꾸면 포지션 버튼이 바뀌고, 고른 포지션이 표시된다
- [ ] 타석(우타·좌타), 투구(우투·좌투), 출신을 바꾼 대로 선수가 만들어진다 (홈 탭의 선수 카드에서 확인)
- [ ] 타자, 선발 투수, 불펜 투수로 각각 한 번씩 만들어 본다 (다시 만들려면 `save-baseball-player.json`을 지운다)
- [ ] 만든 뒤 홈 탭에 선수 카드, 훈련 포인트 100,000 P, 시즌 목표, 다음 경기가 나온다

### 2. 토큰이 훈련 포인트로 쌓이는지

- [ ] Claude Code를 쓰면 20초쯤 뒤에 훈련 포인트가 오른다
- [ ] 홈 탭의 "오늘 번 포인트"가 선수를 만든 뒤에 쓴 토큰만 센다
- [ ] 상단바에 `1.2M P`처럼 포인트가 나오고, 마우스를 올리면 "훈련 포인트"가 보인다
- [ ] **Gemini CLI**를 쓰는 맥에서 포인트가 오른다 (실제 로그로 확인한 적이 없다)
- [ ] **opencode**를 쓰는 맥에서 포인트가 오른다 (실제 로그로 확인한 적이 없다)
- [ ] 같은 토큰이 두 번 세어지지 않는다 (앱을 껐다 켜도 포인트가 갑자기 늘지 않는다)

### 3. 훈련

- [ ] 훈련 버튼을 누르면 버튼에 적힌 만큼 능력치가 오르고 포인트가 줄어든다. 능력(선수 카드의 숫자)은 어떤 훈련이든 0.25 오른다
- [ ] 같은 훈련을 다시 하면 버튼의 비용이 조금 올라 있다
- [ ] 두 번 훈련하면 모든 훈련 버튼이 꺼지고, 경기를 한 번 치르면 다시 켜진다
- [ ] 포인트가 모자라면 버튼이 꺼지고, 마우스를 올리면 이유가 나온다
- [ ] 설정의 가격 난이도를 바꾸면 훈련 비용이 따라 바뀐다
- [ ] 한계 돌파 훈련은 포인트가 3,000만 이상일 때만 켜진다

### 4. 경기와 중계

- [ ] "경기 시작"을 누르면 중계가 시작되고, 스코어보드 아래에 "내 선수" 줄이 나온다
- [ ] 타자: 타석에 설 때마다 내 선수 줄의 기록이 바뀌고, 문자 중계의 내 선수 장면이 강조된다
- [ ] 선발 투수: 등판하는 날에는 1회부터 던지고, 쉬는 날에는 홈 탭에 "등판하지 않는 날"이라고 미리 나온다
- [ ] 불펜 투수: 선발이 내려간 뒤 가장 먼저 올라온다
- [ ] 경기가 끝나면 경기 탭 "지난 경기"에 평점, 감독 신뢰 변화, 연봉이 나온다
- [ ] 중계 도중 앱을 껐다 켜면 그 경기가 이어진다
- [ ] 팝오버를 닫아도 경기가 진행되고, 상단바에 스코어가 나온다

### 5. 계약과 이적

제안은 확률로 오기 때문에 시간이 걸린다. 오프시즌(시즌이 끝난 뒤 친선 5경기)에 가장 자주 온다.

- [ ] 제안이 오면 홈 탭에 주황색 알림이 뜨고, 누르면 커리어 탭으로 간다
- [ ] 수락하면 소속 구단이 바뀌고, 다음 경기를 그 구단에서 치른다
- [ ] 투수가 구단을 옮긴 뒤에도 곧바로 등판한다 (고친 버그라서 한 번 더 본다)
- [ ] "연봉 올려 달라고 하기"는 제안마다 한 번만 된다
- [ ] 답하지 않은 이적 제안은 다음 경기가 끝나면 사라진다
- [ ] "이적 요청"을 누르면 감독 신뢰가 10 떨어지고 버튼이 꺼진다
- [ ] 계약이 끝났는데 재계약하지 않으면 무소속이 되고, 입단 제안 중 하나를 골라야 경기를 할 수 있다

### 6. 모드 전환과 저장

- [ ] 설정 탭 "모드"에서 야구 구단 ↔ 야구 선수 ↔ 축구 구단을 오갈 수 있다
- [ ] 다른 모드에 다녀와도 선수가 그대로 있다
- [ ] 쉬는 동안 쓴 토큰은 돌아왔을 때 포인트로 들어오지 않는다
- [ ] 쉬는 동안에는 경기 기회가 쌓이지 않는다
- [ ] 저장 폴더에 `save.json`, `save-football.json`, `save-baseball-player.json`이 따로 생긴다
- [ ] **예전부터 하던 야구 구단 저장 파일**을 복사해 와서 열어도 그대로 이어진다 (원본은 건드리지 않는다)

### 7. 기존 구단 모드가 그대로인지

선수 모드를 넣으면서 경기·시즌 코드를 건드렸다. 자동 테스트가 지키고 있지만 화면은 한 번 본다.

- [ ] 야구 구단: 홈, 경기, 리그, 구단, 선수, 설정 탭이 예전과 같다
- [ ] 야구 구단: 경기 탭에 "투수 운용 방침"이 그대로 있다
- [ ] 야구 구단: 리그 탭에서 다른 팀 선수에게 이적 제안을 보낼 수 있다
- [ ] 축구 구단: 경기 한 번을 끝까지 치른다

### 8. 축구 선수 모드

- [ ] 처음 화면에서 "축구 선수"를 고르면 포지션 네 개와 출신만 묻는 만들기 화면이 나온다
- [ ] 포지션을 누르면 설명이 바뀐다 (골키퍼는 "가장 오래 걸리는 포지션" 안내)
- [ ] 홈 탭의 다음 경기 안내가 "선발" 또는 "몇 분쯤 교체"로 나온다
- [ ] 벤치에서 시작한 경기: 중계의 내 선수 줄이 "벤치에서 대기 중"이다가, 안내된 시간쯤에 교체 문구와 함께 평점으로 바뀐다
- [ ] 경기 탭의 플레이 스타일을 바꾸면 설명이 바뀌고, 앱을 껐다 켜도 남아 있다
- [ ] 욕심내기로 몇 경기 하면 슈팅 수가 눈에 띄게 는다
- [ ] 골키퍼: 주전이 아니면 네 경기에 한 번만 나오고, 나머지 경기는 "출전하지 않았습니다"로 끝난다
- [ ] 커리어 탭의 "주전 경쟁" 카드에 같은 포지션 선수들과 선발 자리 수가 나온다
- [ ] 퇴장당한 다음 경기에 홈 탭 안내가 "출장 정지"로 나오고 그 경기에 나오지 않는다

### 9. 전문가 검토 뒤에 바뀐 것

- [ ] 선수 모드 훈련 버튼이 "+0.8 · 400.0K P"처럼 능력치 증가량을 보여 준다
- [ ] 능력이 리그 한도(6부는 45)에 닿으면 훈련 버튼이 꺼지고 이유가 나온다. 윗 리그로 옮기면 다시 켜진다
- [ ] 야구 선발 투수: 등판하지 않은 날 뒤에는 남은 훈련이 3/2로 나온다 (한 번 더)
- [ ] 야구 구단: 방금 던진 선발을 "다음 경기 선발"로 고르면 "아직 쉬어야 합니다"가 나온다
- [ ] 야구 구단: 리그 탭 안내가 "2위와 3위는 와일드카드"로 나온다
- [ ] 축구 구단: 리그 탭에 "승격 조건: 구장 등급" 카드가 나오고 신청 버튼이 없다
- [ ] 축구 구단: 퇴장당한 선수가 로스터에 "출장 정지"로 표시되고 다음 경기 선발에서 빠진다
- [ ] 축구 구단: 오프시즌에 "유소년 승급" 후보 세 명이 온다
- [ ] 축구 구단: 4~16라운드에는 이적 시장이 닫혀 있다

## 시간이 오래 걸리는 것

실시간으로는 한 시즌에 여드레쯤 걸려서 직접 보기 어렵다. 자동 테스트로는 지나가는 것을 확인했고, 화면은 보지 못했다.

- [ ] 정규시즌이 끝날 때 시즌 목표 달성 여부가 소식에 나온다
- [ ] 수상하면 커리어 탭 "통산"에 남는다
- [ ] 소속 구단이 승격하거나 강등되면 다음 시즌을 그 리그에서 뛴다
- [ ] 야구: 2위나 3위로 마치면 승격 와일드카드, 이기면 윗 리그 9위와 승강 플레이오프를 치른다
- [ ] 축구: 2~5위로 마치면 준결승 1차전(원정 또는 홈) → 2차전 → 결승 순으로 치른다. 2차전에서 합산이 같으면 연장으로 간다
- [ ] 시즌이 바뀌면 커리어 탭에 시즌별 기록이 한 줄 늘어난다
- [ ] 30세부터 오프시즌에 "은퇴" 버튼이 나온다
- [ ] 은퇴하면 기록 화면이 나오고, 새 선수를 만들면 같은 세계에서 다시 시작한다

빨리 보려면 테스트 코드의 `CareerAuto`(`Tests/TokenBaseballCoreTests/CareerTestSupport.swift`)로 저장 파일을 원하는 시점까지 돌려 만든 뒤 그 파일로 앱을 띄운다. 화면 그림만 필요하면 다음으로 뽑는다. [플레이 가이드](guide/README.md)의 그림도 이렇게 만들었다.

```sh
TOKEN_BASEBALL_SAVE=/tmp/tb-test/save.json TOKEN_BASEBALL_SNAPSHOT=/tmp/tb-snap swift run TokenBaseball
```

## 재미와 속도 (정답이 없는 것)

며칠 해 보고 판단할 것들이다. 수치는 `Sources/TokenBaseballCore/Balance.swift`의 "선수 모드" 부분에 모여 있다.

- [ ] 성장 속도: 평소 쓰는 토큰 양으로 한 시즌에 능력이 얼마나 오르는가. 너무 빠르거나 느리면 훈련 횟수(경기 사이 2번)와 비용을 고친다
- [ ] 훈련 비용: 포인트가 계속 남는가, 계속 모자란가
- [ ] 리그 한도: 한 리그에 묶여 답답한가, 적당히 등을 떠미는가
- [ ] 축구 주전 경쟁: 교체로만 나오는 기간이 너무 길지 않은가
- [ ] 야구 경기: 점수와 홈런 수가 자연스러운가 (팀당 4점 안팎, 홈런 1개 안팎)
- [ ] 선발 투수: 나오지 않는 경기를 지켜보는 것이 지루한가
- [ ] 감독 신뢰: 너무 쉽게 100이 되거나 0이 되지 않는가
- [ ] 이적 제안: 너무 자주 오거나 너무 안 오지 않는가
- [ ] 평점: 잘한 경기와 못한 경기가 평점으로 납득이 되는가
