## 모든 모드에 공통인 것

- **토큰이 재화다.** Claude Code, Codex, Gemini CLI, opencode에서 쓴 토큰을 로컬 로그에서 읽는다. 구단 경영에서는 구단 자금(1토큰 = 1원), 개인 성장에서는 훈련 포인트(1토큰 = 1 P)가 된다. 구단이나 선수를 만든 뒤에 쓴 토큰만 세고, 20초마다 반영된다.
- **경기는 1시간에 한 번.** 경기 기회는 1시간에 하나씩, 최대 3개까지 쌓인다. "경기 시작"을 직접 눌러야 하고, 한 경기는 실시간 문자 중계로 15분쯤 걸린다. 배속과 건너뛰기는 없다.
- **6부 리그.** 6부 시민 아마추어에서 시작해 1부 프로까지 올라간다. 리그마다 10팀이 36라운드를 치르고, 시즌이 끝나면 플레이오프와 친선 5경기를 치르는 오프시즌이 있다.
- **승격과 강등은 반드시 있다.** 방식은 종목마다 다르다. 야구는 직접 만든 방식(와일드카드 + 승강 플레이오프), 축구는 잉글랜드 리그 방식(2팀 승격·2팀 강등, 승격 플레이오프)이다 → [리그](../03-league.md#승강).
- **개인 성장의 훈련.** 어떤 훈련이든 능력이 같은 양만큼 오르고, 경기 사이에 두 번 한다. 지금 리그 수준을 넘으면 윗 리그로 올라가야 더 훈련할 수 있다.
- **모드는 따로 저장된다.** 설정 탭의 "모드"에서 오간다. 한 번에 하나만 진행하고, 쉬는 쪽은 그동안 쓴 토큰을 받지 않으며 경기 기회도 쌓이지 않는다.
- **상단바.** 평소에는 훈련하는 모습과 숫자 하나(자금 또는 훈련 포인트, 오늘 사용량, 다음 경기까지 남은 시간 중 설정에서 고른 것)가 나온다. 경기 중에는 스코어가 나온다.

경기 규칙과 훈련, 승강제는 축구·야구 전문가 관점의 검토를 거쳐 고쳤다. 무엇을 지적받고 무엇을 고쳤는지는 → [전문가 검토](../review/README.md).

화면 그림은 `TOKEN_BASEBALL_SNAPSHOT=폴더 swift run TokenBaseball`로 뽑은 예시 화면이다. 구단과 선수 이름은 모두 가상이다.
