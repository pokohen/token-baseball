# 2. 경기

## 경기 진행

✅ 경기는 1시간마다 한 번, 직접 눌러서 진행한다.

💡 진행 방식:
- 마지막 경기를 시작한 시각에서 1시간이 지나면 **경기 시작** 버튼이 켜진다.
- 내 팀이 한 경기를 치르면 같은 리그의 다른 경기들도 같은 **라운드**로 함께 진행된다. 리그 전체가 내 경기 속도에 맞춰 흘러간다.
- 시즌 36경기면 최소 36시간이 걸린다. 하루에 몇 경기씩 하면 1~2주에 한 시즌이 끝난다.

❓ 경기 기회를 쌓아 둘 수 있는지.
- A안: 쌓이지 않는다. 1시간이 지나면 버튼이 켜질 뿐이다 (자주 열어보게 됨)
- B안: 최대 3경기까지 쌓인다 (자고 일어나서 몰아서 할 수 있음)
- 💡 B안 추천. 상주 앱이지만 사용자가 계속 지켜보지는 않으므로

## 실시간 중계

✅ 경기는 결과가 바로 나오지 않는다. 실제 야구처럼 시뮬레이션이 **한 구 한 구** 실제로 돌아간다.

✅ 배속은 없다. 모든 경기는 같은 속도로 진행되고, 결과로 바로 건너뛰는 기능도 없다.

💡 진행 속도: 공 하나에 약 3초, 한 경기(약 280구)에 **약 15분**.

- 이닝 교대, 투수 교체, 득점 장면에서는 잠깐 멈췄다 간다.
- 팝오버를 닫아도 경기는 백그라운드에서 계속 진행된다. 다시 열면 지금 상황부터 보인다.

### 중계 화면

```
┌──────────────────────────────────────────┐
│  1 2 3 4 5 6 7 8 9   R  H  E             │
│ 원정 0 0 1 0 2 0 0      3  7  0          │
│ 홈   1 0 0 0 1 0        2  5  1          │
├──────────────────────────────────────────┤
│        ◇ 2루                  7회초      │
│   ◇ 3루     ◆ 1루            B ●●○       │
│        ⌂ 홈                   S ●○       │
│                              O ●○        │
├──────────────────────────────────────────┤
│ 투수 박○○  78구  │ 타자 김○○  2타수 1안타 │
├──────────────────────────────────────────┤
│ 3구째 슬라이더, 바깥쪽 헛스윙!            │
│ 2구째 직구 146km, 볼                      │
│ 1구째 커브, 스트라이크 (루킹)             │
└──────────────────────────────────────────┘
```

- **스코어보드**: 이닝별 점수, 안타(H), 실책(E)
- **다이아몬드**: 주자 위치, 타구 방향 표시
- **볼카운트**: 볼·스트라이크·아웃
- **매치업**: 현재 투수(투구 수)와 타자(오늘 기록)
- **문자 중계**: 투구마다 구종, 구속, 결과
- 💡 **타 구장 소식**: 같은 라운드의 다른 경기도 동시에 돌아가며, 중계 하단에 점수가 흘러간다 (예: "부산 4 : 2 대구 6회말")

### 경기 중 상단바

상단바 표시 설정(자금 / 오늘 사용량 / 다음 경기)과 상관없이 경기 상황을 보여준다 → [메인](01-main.md#상단바-메뉴바)

- 💡 경기 중: 실시간 스코어 `⚾ 3:2 7회초`. 득점하면 잠깐 반짝인다.
- ✅ 경기가 끝나면 `⚾ 경기 종료`를 표시한다. 💡 `승 5:3`처럼 결과를 짧게 붙이고, 팝오버를 열어 확인할 때까지 남겨 둔다.
- 💡 알림(설정에서 끌 수 있음): 내 팀 득점, 역전, 경기 종료.

### 감독 개입

💡 처음에는 개입하지 않는다. 라인업, 선발 투수, 투수 운용 방침(교체 기준 투구 수, 마무리 투입 조건)은 경기 전에 정하고, 경기는 그 방침대로 흘러간다.

💡 나중에 넣을 수 있는 작전: 번트, 도루, 고의사구, 투수 교체, 대타. 실시간 중계라서 경기 중 개입을 붙이기 좋다.

## 야구 규칙

✅ 기본 야구 규칙을 따른다. 정규시즌 운영은 KBO 방식을 참고한다.

| 항목 | 규칙 |
|---|---|
| 이닝 | 9이닝, 이닝당 3아웃 |
| 말 공격 생략 | 9회초가 끝났을 때 홈팀이 이기고 있으면 9회말을 하지 않음 |
| 끝내기 | 9회말 이후 홈팀이 앞서는 순간 경기 종료 |
| 연장 | 💡 KBO 정규시즌처럼 최대 11회. 그래도 동점이면 무승부 |
| 승부치기 | 없음 |
| 지명타자 | 사용 (투수는 타석에 서지 않음) |
| 콜드게임 | 💡 시민 리그(4~6부)만 5회 이후 10점 차, 7회 이후 7점 차 |

❓ 콜드게임을 하위 리그에만 둘지, 아예 뺄지

## 시뮬레이션

✅ 투구 단위로 실제로 시뮬레이션한다. 결과를 미리 정해 놓고 보여주는 것이 아니다.

### 한 구의 흐름

```
투수: 구종·코스 선택 → 투구 (구속, 제구 오차)
   │
타자: 스윙 여부 판단 (선구안)
   │
   ├─ 안 침 → 볼 / 스트라이크 (존 안이면 루킹 스트라이크)
   └─ 침   → 헛스윙 / 파울 / 인플레이
                                 │
                       타구 생성: 속도·각도·방향 (파워, 컨택)
                                 │
                       수비 판정: 수비 범위·어깨 → 아웃 / 안타 / 실책
                                 │
                       주자 진루: 주력, 타구 위치, 송구
```

| 단계 | 쓰는 능력치 |
|---|---|
| 구종·코스 선택 | 투수 성향, 볼카운트 (불리하면 존 안쪽) |
| 구속·제구 | 구위, 제구, 남은 체력 |
| 스윙 판단 | 타자 선구안, 볼카운트 |
| 맞히기 | 타자 컨택 vs 투수 구위·변화구 |
| 타구 질 | 타자 파워, 맞힌 정도 |
| 수비 | 야수 수비·어깨, 타구 방향 |
| 진루 | 주자 주력, 외야수 어깨 |

선수 능력치는 → [선수 영입](05-player-recruitment.md#능력치)

### 투구 사이 이벤트

💡 공과 공 사이에도 일이 일어난다: 도루 시도, 견제, 폭투·포일, 투수 교체, 대타·대주자.

### 체력과 투수 교체

- 투수는 공을 던질수록 체력이 줄고, 구속과 제구가 떨어진다.
- 💡 투구 수, 실점, 체력을 보고 투수 운용 방침에 따라 불펜으로 바꾼다.
- 💡 선발 투수는 등판 후 4~5경기 쉬어야 다시 선발로 나온다.

### 기타

- 💡 홈 경기 보정: 홈팀은 작은 보정(+2% 정도)을 받는다. 경기장 레벨이 높을수록 커진다 → [구단 운영](04-club-management.md#경기장).
- 💡 같은 입력이면 같은 결과가 나오도록 경기마다 시드를 저장한다 (재현과 디버깅용). 앱을 껐다 켜도 진행 중인 경기를 이어서 볼 수 있다.
- 다른 경기도 같은 엔진으로 투구 단위로 돌린다. 화면에 그리지 않을 뿐이다 → [세계 시뮬레이션](06-world-simulation.md)

## 경기 결과의 영향

| 항목 | 승리 | 무승부 | 패배 |
|---|---|---|---|
| 순위 | 승 +1 | 무 +1 | 패 +1 |
| 인지도 | 💡 +3 | +1 | +0 |
| 선수 경험치 | 출전 선수 모두 받음. 활약도에 따라 추가 | | |
| 관중 수입 | 💡 홈 경기만. 경기장 수용 인원 × 인지도 비율 | | |

💡 순위는 KBO처럼 **승률 = 승 / (승 + 패)** 로 정하고 무승부는 빼고 계산한다.

## 기록

💡 시즌별로 쌓는 기록:
- 팀: 승·무·패, 득점, 실점, 팀 타율, 팀 평균자책점
- 타자: 타율, 홈런, 타점, 도루, OPS
- 투수: 승, 패, 세이브, 평균자책점, 탈삼진, 이닝, 투구 수

💡 시즌이 끝나면 리그 시상(MVP, 홈런왕, 다승왕 등)을 하고, 수상하면 인지도 보너스를 준다.
