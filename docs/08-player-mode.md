# 8. 선수 모드

구단을 운영하는 대신 **축구 선수 한 명**이 되어 커리어를 보내는 모드다. 아직 만들지 않았다. 이 문서는 기획이다.

구단 모드(야구, 축구)는 그대로 남는다. 이 문서는 선수 모드에서 **달라지는 것만** 적는다. 여기 없는 내용(6부 리그와 승강, 일정, 축구 규칙과 경기 엔진, 능력과 잠재력, 나이 곡선, 세계 시뮬레이션)은 1~7번 문서를 그대로 따른다.

## 한 줄 소개

✅ 내가 축구 선수가 된다.

💡 16세에 동네 시민 구단에 입단해, 코딩하며 쓴 토큰으로 훈련하고, 주전을 따내고, 더 높은 리그의 구단으로 옮겨 가며 1부 프로 리그의 스타가 되는 것이 목표다.

| | 구단 모드 | 선수 모드 |
|---|---|---|
| 내가 되는 것 | 구단주 겸 단장 | 선수 한 명 |
| 토큰 | 구단 자금 | 훈련 포인트 |
| 키우는 것 | 구단 (시설, 선수단, 인지도) | 내 선수 (능력치, 감독 신뢰, 명성) |
| 올라가는 길 | 구단이 승격한다 | 구단이 승격하거나, 내가 상위 리그 구단으로 이적한다 |
| 실패 | 파산 | 없음 (방출돼도 다른 구단을 찾는다) |
| 끝 | 없음 | 은퇴 |

## 핵심 루프

```
코딩한다 (토큰 사용)
   ↓
훈련 포인트가 쌓인다
   ↓
훈련한다: 능력치를 골라 올린다
   ↓
1시간마다 경기에 나선다 (선발 / 교체 / 벤치는 감독이 정한다)
   ↓
경기 평점이 나온다
   ↓
평점이 쌓이면 감독 신뢰와 명성이 오른다
   ↓
주전이 되고, 연봉이 오르고, 더 큰 구단에서 제안이 온다
```

## 시작

💡 선수를 만들 때 정하는 것:

| 항목 | 내용 |
|---|---|
| 이름 | 직접 입력 |
| 포지션 | 골키퍼 / 수비수 / 미드필더 / 공격수 중 하나. 커리어 중에는 바꿀 수 없다 |
| 연고지 | 구단 모드처럼 도시를 고른다. 그 도시의 6부 시민 구단에 입단한다 |
| 등번호 | 💡 고른다 (화면 표시용) |

💡 정해져 있는 것:

- **나이 16세**로 시작한다.
- **능력**: 입단한 구단에서 같은 포지션 선수 중 **주전 바로 다음** 수준으로 맞춘다. 처음부터 주전은 아니지만 교체로는 나올 수 있다.
- **잠재력**: 💡 75~90 사이에서 정해지고 숨겨져 있다. 1부 프로 리그 주전(능력 70대)까지는 누구나 갈 수 있고, 그 위는 운과 각성에 달렸다.
- **특성**: 처음에는 없다. 커리어 중에 얻는다 → [특성](#특성과-각성).
- 세계는 구단 모드와 똑같이 만든다. 6개 리그 60개 구단이 모두 CPU 구단이다.

❓ **야구 선수 모드도 만들지** — 💡 축구부터 만든다. 야구는 타자와 투수가 하는 일이 너무 달라서 따로 기획해야 한다.

## 토큰 → 훈련 포인트

✅ 토큰 수를 가중치 없이 그대로 쓰는 원칙은 같다.

```
훈련 포인트 = 총 토큰 = input + output + cache_write + cache_read
```

- 선수를 만든 뒤에 쓴 토큰만 센다. 💡 시작할 때 100,000 포인트를 갖고 있다 (구단 모드의 시작 자금과 같다).
- 훈련 포인트는 **훈련에만** 쓴다. 연봉은 따로 쌓인다 → [계약과 연봉](#계약과-연봉).

### 훈련

💡 훈련 탭에서 능력치를 골라 올린다. 능력치는 축구 구단 모드의 여덟 가지와 같다 (슈팅, 패스, 드리블, 수비, 스피드, 피지컬, 골키핑, 체력).

- 능력치 하나를 +1 올리는 데 드는 포인트는 **지금 값이 높을수록 비싸다**.

| 지금 값 | +1에 드는 포인트 (💡) |
|---|---|
| 40 미만 | 30만 |
| 40~54 | 80만 |
| 55~69 | 200만 |
| 70~79 | 500만 |
| 80 이상 | 1,200만 |

- 설정의 **가격 난이도 슬라이더(10%~200%)** 가 이 비용에도 적용된다.
- 내 포지션에서 중요한 능력치(→ [축구 모드의 가중치 표](07-football.md#능력치))를 올려야 능력(CA)이 많이 오른다. 무엇을 올릴지가 선수의 스타일이 된다: 슈팅만 올린 공격수, 패스와 스피드를 올린 공격수.

💡 토큰을 많이 쓴 날 하루 만에 다 크지 않도록 두는 제한:

1. **잠재력**: 능력(CA)은 잠재력을 넘지 못한다. 잠재력에 가까워질수록 비용이 더 든다 (남은 여유가 10 이하면 2배).
2. **훈련 횟수**: 경기와 경기 사이에 **세 번**까지만 훈련할 수 있다 (한 번에 +1). 쓰지 못한 포인트는 그대로 남아 다음에 쓴다.
3. **나이**: 31세부터는 훈련으로 올릴 수 없고 유지만 한다. 34세부터는 시즌마다 스피드와 체력부터 떨어진다 (구단 모드의 나이 곡선과 같다).

- 💡 포인트를 쓰지 않아도 조금씩은 큰다. 구단 모드의 성장 공식(나이, 잠재력 여유, 구단 훈련소 레벨, 출전 시간)이 내 선수에게도 그대로 적용된다. 토큰 훈련은 그 위에 더해진다.

❓ **훈련 횟수 제한을 둘지** — 💡 둔다. 없으면 토큰을 많이 쓰는 사람은 며칠 만에 잠재력에 닿아 할 일이 없어진다. 대신 답답하면 "경기 사이 세 번"을 늘리면 된다.

## 경기

✅ 경기 기회(1시간에 하나, 최대 3개), 직접 눌러 시작, 약 15분의 실시간 중계, 배속·건너뛰기 없음은 구단 모드와 같다.

- 내 구단의 경기가 통째로 중계된다. 화면도 축구 구단 모드의 중계 화면을 그대로 쓴다.
- 💡 내 선수가 관여한 장면은 문자 중계에서 강조된다 (굵게, 색).
- 💡 스코어보드 아래에 **내 선수 줄**이 생긴다: 출전 상태(선발 / 벤치 / 교체 투입 73'), 지금까지의 평점, 골·도움, 남은 체력.
- 💡 상단바: 경기 중에는 구단 모드와 같이 `⚽ 1:0 67'`. 내가 골을 넣으면 `⚽ 골! 1:0 67'`로 잠깐 바뀐다.

### 출전: 벤치에만 앉아 있지 않게

구단 모드에서 선발은 능력 순으로 정해진다. 그대로 두면 막 입단한 내 선수는 뛰지 못하고, 내가 나오지 않는 경기를 15분씩 보게 된다. 그래서 선수 모드에는 **감독 신뢰**를 둔다.

💡 **감독 신뢰 (0~100)**: 감독이 나를 얼마나 믿는지. 능력과 함께 출전을 정한다.

| 출전 | 조건 (💡) |
|---|---|
| 선발 | 같은 포지션에서 `능력 + 신뢰 보정`이 선발 자리 안에 든다 |
| 교체 투입 | 선발이 아니면 **반드시** 교체로 나온다. 신뢰가 높을수록 일찍 나온다 (신뢰 20이면 80분, 60이면 60분) |
| 벤치 | 골키퍼만 해당. 골키퍼는 교체로 나오지 않으므로 아래 규칙을 따른다 |

- 신뢰 보정: 신뢰 50을 기준으로 능력에 −5 ~ +5를 더해 비교한다. 신뢰가 높으면 능력이 조금 낮아도 선발로 나온다.
- 신뢰는 **경기 평점**으로 오르내린다. 평점 7.0 이상이면 오르고 6.0 아래면 내린다. 훈련을 꾸준히 해도 조금 오른다.
- 새 구단으로 옮기면 신뢰는 💡 40에서 다시 시작한다.
- 💡 **골키퍼**: 교체로 나올 수 없으니, 주전이 아닐 때는 친선 경기와 💡 리그 경기 네 번 중 한 번에 선발로 나온다. 골키퍼는 주전을 따내기 전까지 가장 느린 포지션이라고 창단 화면에서 알려 준다.

❓ **선발이 아닐 때 반드시 교체로 나오게 할지** — 💡 그렇게 한다. 현실적이지는 않지만, 한 시간에 한 번 15분을 보는 게임에서 내가 한 번도 안 나오는 경기는 재미가 없다.

### 경기 전에 정하는 것

✅ 경기 중에는 개입하지 않는다 (구단 모드와 같다).

💡 경기 전에 **플레이 스타일**을 하나 고른다.

| 스타일 | 효과 |
|---|---|
| 균형 | 없음 |
| 욕심내기 | 슈팅을 더 많이 가져간다. 도움이 줄고, 공을 뺏기는 일이 늘어난다 |
| 연계 | 패스와 도움 기회가 늘고 슈팅이 줄어든다 |
| 수비 가담 | 태클과 가로채기가 늘고 체력이 빨리 줄어든다. 공격 관여가 줄어든다 |

포메이션, 전술 성향, 선발 11명은 감독(CPU)이 정한다. 포메이션에 따라 내 포지션의 자리가 줄 수 있다 (예: 4-2-3-1은 공격수가 한 명).

### 경기 평점

💡 경기가 끝나면 1.0~10.0의 평점이 나온다. 6.0이 "무난했다"이다.

```
평점 = 6.0 + 한 일의 합 − 못한 일의 합 (+ 팀 결과 보정)
```

| 한 일 | 💡 |
|---|---|
| 골 | +1.0 (결승골이면 +0.3 더) |
| 도움 | +0.6 |
| 유효 슈팅 | +0.15 |
| 기회를 만든 패스 (슈팅으로 이어진 패스) | +0.2 |
| 전진 성공 (우리 진영 → 중원, 중원 → 상대 진영) | +0.05 |
| 돌파 성공 | +0.1 |
| 태클·가로채기 성공 | +0.15 |
| 걷어내기·슈팅 막기 | +0.15 |
| 선방 (골키퍼) | +0.25 (페널티킥이면 +1.0) |
| 무실점 (골키퍼·수비수, 60분 이상 뛰었을 때) | +0.5 |

| 못한 일 | 💡 |
|---|---|
| 공을 뺏김 | −0.1 |
| 반칙 | −0.1 |
| 경고 | −0.3 |
| 퇴장 | −1.5 |
| 실점 (골키퍼) | −0.3 |
| 페널티킥 실축 | −0.5 |

- 팀 결과 보정: 이기면 +0.2, 지면 −0.2.
- 출전 시간이 짧으면 평점이 6.0 쪽으로 당겨진다 (10분 뛰고 9.0이 나오지 않게).
- 포지션마다 평점이 고르게 나오도록 수치를 맞춘다. 기준: 평균 능력의 선수가 90분 뛰면 포지션과 상관없이 평균 6.5 근처.

**지금 엔진에 없는 기록**

지금 선수별로 남는 기록은 골, 도움, 슈팅, 유효 슈팅, 경고, 퇴장, 선방, 실점, 무실점뿐이다. 수비수와 미드필더는 평점을 매길 근거가 없다. 선수 모드를 만들 때 다음을 선수별로 남겨야 한다.

- 출전 시간(분)
- 전진 성공, 기회를 만든 패스
- 돌파 성공, 공을 뺏긴 횟수
- 태클·가로채기, 걷어내기·슈팅 막기
- 반칙

지금 문자 중계는 이런 장면에서 선수 이름을 그 자리 선수 중에 무작위로 고른다. 그 선수에게 기록을 남기면 된다. 평점은 구단 모드의 시상(MVP)에도 쓸 수 있다.

## 내 선수가 쌓는 것

| 값 | 뜻 | 어디에 쓰이나 |
|---|---|---|
| **능력치·능력(CA)** | 실력 | 경기, 출전, 이적 제안 |
| **감독 신뢰** | 지금 구단 감독의 평가 | 출전 |
| **명성** (0~100) | 리그에 이름이 알려진 정도 | 이적 제안의 수와 수준, 연봉 협상, 시상 |
| **통산 기록** | 경기, 골, 도움, 평균 평점, 수상, 거쳐 간 구단 | 커리어 화면, 은퇴 뒤 기록 |
| **통산 수입** | 받은 연봉의 합 | 점수처럼 보여 준다 (쓰는 곳은 처음에는 없다) |

- 💡 명성은 평점 좋은 경기, 시즌 기록, 수상, 상위 리그 진출로 오른다. 구단 모드의 인지도처럼 시즌이 끝나면 조금 줄어든다.

### 특성과 각성

- 💡 **특성**은 조건을 채우면 얻는다. 예: 한 시즌에 동점·한 골 차 상황에서 5골 → "찬스에 강함", 한 시즌 2,500분 이상 출전 → "강철 체력", 프리킥·페널티킥 5골 → "프리킥 장인".
- 💡 **각성**: 시즌 MVP, 득점왕 같은 수상을 하면 잠재력이 +3~8 오른다 (구단 모드의 각성 이벤트와 같다).

## 구단과의 관계

### 구단은 누가 운영하나

💡 내 소속 구단도 **CPU 구단**이다. 시설 투자, 영입, 방출, 포메이션, 승격 신청을 모두 구단이 알아서 한다. 나는 지시할 수 없다.

구단 모드에서 "내 구단"에만 있던 규칙은 선수 모드에서 이렇게 된다.

| 구단 모드의 규칙 | 선수 모드 |
|---|---|
| 구단 자금, 시설, 홍보, 인지도 | 없음 (CPU 구단은 지금도 자금 없이 강도 목표로 운영된다) |
| 파산 | 없음 |
| 승격 신청 | CPU 구단은 지금도 순위만으로 승격 플레이오프에 나간다. 내 구단도 같다 |
| 승강 플레이오프 직접 치르기 | 내 구단이 나가면 그 경기를 중계로 본다 |
| CPU 팀 맞춰주기 (내 구단 강도 기준) | 💡 끈다. 기준이 될 "내 구단"이 없다. 경쟁은 팀 안의 주전 경쟁과 이적으로 생긴다 |
| 최소 인원 자동 채우기 | CPU 구단 방식 그대로 |
| 강등 때 선수 유출 | 내 구단이 강등되면 나에게도 이적 제안이 온다 |
| 이적 시장 화면 (영입, 방출, 재계약) | 없음. 대신 **나에게 오는 제안**만 본다 |

### 계약과 연봉

- 💡 계약 기간 1~3시즌, 연봉은 리그와 능력으로 정해진다 (구단 모드의 선수 연봉 공식 그대로).
- 연봉은 시즌이 끝날 때 오른다. 인상 폭에 내 시즌 평균 평점과 수상이 반영된다.
- 받은 연봉은 **통산 수입**으로 쌓인다.
- 계약 마지막 시즌에는 구단이 **재계약 제안**을 할 수 있다 (신뢰와 평점이 좋을 때). 수락하거나, 거절하고 다른 구단의 제안을 기다릴 수 있다.

### 이적

✅ 이적 기간은 구단 모드와 같다: 오프시즌(친선 5경기)과 시즌 중 트레이드 마감 전.

💡 이적 기간에는 경기가 끝날 때마다 제안이 올 수 있다.

- **누가 제안하나**: 내 능력이 그 구단의 같은 포지션 주전과 비슷하거나, 내 명성이 그 리그 수준에 닿았을 때. 보통 같은 리그나 한 단계 위 리그의 구단이다.
- **제안 내용**: 구단, 리그, 연봉, 계약 기간, **예상 입지**(주전 / 로테이션 / 유망주).
- **내 선택**: 수락 / 거절 / 연봉 올려 달라고 하기. 다음 경기가 끝날 때까지 답하지 않으면 사라진다.
- 계약이 남아 있어도 옮길 수 있다 (이적료는 구단끼리의 일이고 나와는 상관없다).
- 💡 **이적 요청**: 이적 기간에 한 번, 구단에 이적을 요청할 수 있다. 제안이 올 확률이 오르지만 감독 신뢰가 떨어진다.

💡 **방출과 무소속**

- 계약이 끝났는데 재계약 제안도 다른 제안도 없으면 무소속이 된다.
- 무소속이 되면 바로 **입단 테스트**를 본다: 지금 능력에 맞는 리그의 구단 2~3곳이 계약을 제안하고, 하나를 고른다. 경기를 못 뛰는 기간은 없다.
- 한 단계 아래 리그로 내려갈 수도 있다. 실패가 아니라 주전으로 뛰며 다시 올라가는 길이다.

### 올라가는 두 가지 길

1. **구단과 함께**: 내 구단이 승격하면 나도 그 리그에서 뛴다. 계약이 이어지고 연봉이 리그에 맞춰 오른다.
2. **혼자**: 상위 리그 구단의 제안을 받아 옮긴다. 더 빠르지만 새 구단에서는 주전 경쟁을 다시 해야 한다.

## 시즌과 커리어

- 한 시즌은 구단 모드와 같다: 정규시즌 36라운드, 승강 플레이오프, 친선 5경기.
- 시즌이 끝나면 한 살을 먹는다.

💡 **시즌 목표**: 시즌이 시작될 때 감독이 목표를 하나 준다 (예: "10경기 선발", "5골", "평균 평점 6.8"). 채우면 감독 신뢰와 명성이 오른다. 목표는 내 입지에 맞춰 나온다.

💡 **개인 수상**: 리그 MVP, 득점왕, 도움왕, 최우수 골키퍼(구단 모드에 이미 있다)에 **베스트 11**과 **신인상**(첫 두 시즌)을 더한다.

💡 **커리어 목표** (끝은 아니다): 1부 프로 리그 데뷔 → 1부 주전 → 1부 우승 → 1부 MVP.

### 커리어 길이

하루에 다섯 경기를 하면 한 시즌(41경기)에 여드레쯤 걸린다. 16세부터 36세까지 20시즌이면 **다섯 달**이 넘는다.

❓ **커리어를 얼마나 길게 할지**
- 💡 그대로 둔다. 구단 모드도 끝이 없는 게임이고, 한 선수를 오래 키우는 것이 이 모드의 재미다.
- 대안: 시즌을 짧게 한다 (리그 18라운드, 홈 1·원정 1). 커리어가 석 달쯤으로 줄지만 리그 구조가 구단 모드와 달라진다.

### 은퇴

- 💡 30세부터는 시즌이 끝날 때 스스로 은퇴할 수 있다.
- 💡 37세 시즌이 끝나거나, 무소속이 됐는데 어느 구단도 제안하지 않으면 은퇴한다.
- 은퇴하면 **커리어 기록 화면**이 나온다: 거쳐 간 구단, 통산 경기·골·도움, 평균 평점, 수상, 최고 능력, 통산 수입.
- 💡 은퇴한 선수는 **기록실**에 남는다. 그 뒤 **같은 세계에서** 새 선수를 만들어 다시 시작한다 (구단 모드에서 파산하면 같은 세계에서 새 구단을 만드는 것과 같다). 은퇴한 내 선수의 이름이 기록에 남아 있는 리그에서 뛴다.

❓ **은퇴 뒤에 무엇을 할지**
- 💡 같은 세계에서 새 선수로 다시 시작한다.
- 나중에 검토: 은퇴한 선수가 마지막 구단의 **구단주가 되어 구단 모드로 넘어가기**. 세계를 그대로 이어 쓸 수 있어 잘 맞지만, CPU 구단을 내 구단으로 바꾸는 일이 필요하다.

## 화면

💡 탭 수는 구단 모드와 같게 여섯 개로 둔다.

| 탭 | 구단 모드 | 선수 모드 |
|---|---|---|
| 홈 | 구단 요약, 자금, 다음 경기 | **내 선수 카드**(능력, 포지션, 나이, 소속, 감독 신뢰, 명성), 훈련 포인트, 다음 경기, 시즌 목표, 소식 |
| 경기 | 다음 경기, 중계 | 같다. 전술 카드 대신 **플레이 스타일**, 예상 출전(선발 / 교체) |
| 리그 | 순위, 기록 순위 | 같다 |
| 훈련 (구단 탭 자리) | 시설, 홍보, 재정 | **능력치 올리기**, 남은 훈련 횟수, 특성 |
| 커리어 (선수 탭 자리) | 선수단, 라인업, 영입 | **계약**, 들어온 제안, 시즌 기록, 통산 기록, 팀 동료와 주전 경쟁 상황 |
| 설정 | | 같다. 모드 전환이 여기에 있다 |

**상단바**

- 평소: 내 선수 한 명의 훈련 애니메이션 + 숫자 하나.
- 숫자는 설정에서 고른다: **훈련 포인트** / 오늘 사용량 / 다음 경기까지.
- 경기 중과 경기 종료 표시는 구단 모드와 같다.

## 저장과 모드 전환

지금은 종목별로 저장한다 (`save.json` 야구, `save-football.json` 축구). 선수 모드는 종목이 아니라 **모드**다.

- 💡 선수 모드의 저장 파일은 `save-football-player.json`으로 따로 둔다. 야구 구단, 축구 구단, 축구 선수를 각각 갖고 있을 수 있다.
- 💡 지금 하고 있는 것을 적어 두는 `save.sport`에 값을 하나 더한다 (`baseball` / `football` / `football-player`). 예전 값은 그대로 읽힌다.
- 설정의 "종목" 카드를 **"모드"** 카드로 바꾼다: 야구 구단 / 축구 구단 / 축구 선수. 없는 것을 고르면 만들기 화면이 나온다.
- 처음 시작하는 화면의 첫 단계도 셋 중에 고르게 한다.
- ✅ 한 번에 하나만 한다. 쉬는 구단·선수는 그동안 쓴 토큰을 받지 않고 경기 기회도 쌓이지 않는다 (종목 전환과 같은 규칙).

## 처음 범위

**넣는 것**

- 축구 선수 한 명 만들기, 16세 시작
- 토큰 → 훈련 포인트, 능력치 훈련
- 감독 신뢰와 출전, 플레이 스타일
- 경기 평점과 새 선수별 기록
- 계약, 재계약, 이적 제안, 무소속 입단 테스트
- 시즌 목표, 개인 수상, 특성 얻기
- 은퇴와 기록실, 같은 세계에서 새 선수
- 모드 전환

**나중에 넣을 수 있는 것**

- 야구 선수 모드
- 연봉을 쓰는 곳 (개인 트레이너, 장비, 에이전트)
- 부상과 출장 정지 (축구 구단 모드에도 아직 없다)
- 경기 중 지시, 주장 완장, 팀 동료와의 호흡
- 국가대표
- 은퇴 뒤 구단주가 되어 구단 모드로 넘어가기

## 만드는 순서

1. 이 문서
2. **평점**: 엔진에 선수별 기록을 더하고 평점을 계산한다. 축구 구단 모드에서도 보인다 (경기 뒤 선수 평점, MVP 선정). 여기까지는 선수 모드 없이도 쓸모가 있다
3. **내 구단이 없는 세계**: 지금 코드는 승격, 재정, 이적 시장, 시즌 넘기기가 "내 구단"을 전제로 한다. 내 구단 없이 60개 CPU 구단만으로 한 시즌이 돌아가게 한다. 구단 모드의 동작은 그대로 (야구 고정 시드 테스트로 지킨다)
4. **내 선수**: 만들기, 훈련 포인트와 훈련, 감독 신뢰와 출전, 플레이 스타일
5. **커리어**: 계약, 제안, 이적, 무소속, 시즌 목표, 수상, 은퇴와 기록실
6. **화면**: 홈·훈련·커리어 탭, 중계의 내 선수 줄, 상단바, 모드 전환

💡 3번이 가장 크다. 2번까지 만들어 평점 수치를 먼저 맞춰 보고, 그다음 3번으로 넘어간다.
