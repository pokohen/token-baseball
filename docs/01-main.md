# 1. 메인

## 한 줄 소개

평소처럼 AI 코딩을 하면 쓴 토큰이 구단 자금으로 쌓이고, 그 돈으로 시민 야구단을 프로 구단으로 키운다.

## 핵심 루프

```
코딩 (토큰 사용) ──▶ 구단 자금 적립
                         │
                         ▼
        훈련소 / 경기장 / 홍보 / 선수 영입에 투자
                         │
                         ▼
   1시간마다 경기 진행 ──▶ 승리 · 인지도 상승
                         │
                         ▼
     시즌 종료 ──▶ 승강 플레이오프 ──▶ 상위 리그로 승격
```

- **짧은 루프 (1시간)**: 메뉴바를 열어 경기를 한 번 진행하고, 모인 자금으로 업그레이드한다.
- **중간 루프 (시즌, 36경기)**: 순위 경쟁과 인지도 쌓기, 시즌 종료 후 승강 플레이오프.
- **긴 루프 (여러 시즌)**: 6부 시민 아마추어에서 1부 프로 리그까지.

## 게임 시작

✅ 시민 야구단으로 시작하며, 첫 실행 때 팀 이름을 정한다.

💡 첫 실행 흐름:
1. 환영 화면: 게임 소개, 토큰 사용량을 읽는 로컬 경로 안내
2. **연고지 선택**: 예) 서울, 부산, 대구, 광주, 대전, 인천, 수원, 창원 등. 팀 이름 앞에 붙는다
3. **팀 이름 입력**: 예) "○○ 시민 야구단" 형식의 기본값 제공, 자유 입력 가능
4. 팀 색상과 엠블럼 모양 선택 (몇 가지 프리셋)
5. 시작 로스터 14명 자동 배정 → [선수 영입](05-player-recruitment.md)
6. 시작 자금 **₩100,000** 지급, 6부 시민 아마추어 리그 1시즌 시작

❓ 팀 이름을 나중에 바꿀 수 있게 할지 (예: 승격할 때 "시민" 떼기 이벤트)

## 토큰 → 구단 자금

✅ 토큰 사용량이 구단 자금이 된다.

💡 PokeTokenBar처럼 로컬 로그에서 사용량을 읽는다 (Claude Code `~/.claude/projects/**/*.jsonl`, Codex 등). 외부 서버로 보내지 않는다.

✅ 토큰 수를 가중치 없이 그대로 자금으로 쓴다. 혼자 하는 아케이드 게임이라 다른 사용자와 형평을 맞출 필요가 없다.

```
자금(원) = 총 토큰 = input + output + cache_write + cache_read
```

- PokeTokenBar의 `totalTokens`와 같은 기준이다.
- 💡 사용량은 사람마다 크게 다르므로, 시설·홍보·영입 비용이 너무 싸거나 비싸게 느껴질 수 있다. PokeTokenBar처럼 설정에 **가격 난이도 슬라이더(10%~200%)** 를 두어 자기 페이스에 맞게 비용 배율을 조정한다. 토큰 수 자체는 건드리지 않는다.
- 화면에는 "오늘 번 자금"과 "누적 자금"을 따로 보여준다.
✅ 설치 이전 사용량은 소급하지 않는다. 시작 자금은 **₩100,000** (토큰 100K 분량)이다.
- 💡 시작 직후 살 수 있는 것(입단 테스트, 전단지 등)은 이 금액과 첫 몇 시간 코딩으로 닿을 수 있게 가격을 맞춘다.
❓ 공식 5시간·주간 한도를 다 채웠을 때 보너스를 줄지. PokeTokenBar의 "이상한 사탕"처럼 "스폰서 보너스"를 줄 수 있다

## 상단바 (메뉴바)

✅ 상단바에는 선수들이 훈련하는 모습이 나온다.

✅ 상단바는 짧게 유지한다. **훈련 애니메이션 + 숫자 하나**만 보여주고, 어떤 숫자를 보일지는 설정에서 하나를 고른다.

| 설정 | 예시 |
|---|---|
| **구단 자금** (💡 기본) | `🏃 ₩3.2억` |
| **오늘 사용량** | `🏃 120.5M` |
| **다음 경기** | `🏃 0:23` (경기 가능하면 `🏃 경기 가능`) |

- 자금은 줄여서 표시한다 (예: `₩3.2억`, `₩8,500만`). 오늘 사용량은 PokeTokenBar처럼 `120.5M` 형식이다.
- 💡 설정과 상관없이, 마우스를 올리면 세 가지(자금, 오늘 사용량, 다음 경기)를 모두 툴팁으로 보여준다.
- 💡 "다음 경기"를 고르지 않았어도 경기가 가능해지면 아이콘에 작은 점(배지)을 띄운다.

✅ 경기 상황은 설정과 상관없이 보여준다.

| 상황 | 예시 |
|---|---|
| 경기 중 | 💡 `⚾ 3:2 7회초` (실시간 스코어) |
| **경기 종료** | ✅ `⚾ 경기 종료` · 💡 결과에 따라 `승 5:3` / `패 2:4` 를 함께 짧게 표시 |

- 💡 "경기 종료" 표시는 팝오버를 열어 결과를 확인할 때까지 남아 있고, 그 뒤 원래 설정한 숫자로 돌아간다.

→ [경기 중 상단바](02-match.md#경기-중-상단바)

💡 훈련 애니메이션은 작은 픽셀 스프라이트로 만들고, 훈련 종류별로 돌아가며 보여준다.

| 훈련 | 모습 | 언제 |
|---|---|---|
| 타격 | 배트 스윙 | 기본 |
| 투구 | 와인드업 → 투구 | 기본 |
| 수비 | 땅볼 잡고 송구 | 기본 |
| 주루 | 베이스 사이를 달리기 | 기본 |
| 웨이트 | 바벨 들기 | 훈련소 Lv3 이상 |
| 휴식 | 벤치에 앉아 물 마시기 | 토큰 사용이 일정 시간 없을 때 |

- 토큰을 많이 쓰는 중이면 애니메이션 속도가 빨라진다 (사용량 = 훈련 강도).
- 훈련소 레벨이 오르면 시설 배경이 바뀐다 (공터 → 학교 운동장 → 전용 훈련장).
- 설정에서 애니메이션을 끄고 숫자만 볼 수 있다.

## 화면 구성 (팝오버)

💡 메뉴바 아이콘을 누르면 팝오버가 열린다. 탭 구성:

| 탭 | 내용 |
|---|---|
| **홈** | 팀 엠블럼과 이름, 현재 리그와 순위, 자금, 다음 경기 버튼, 오늘 토큰 사용량 |
| **경기** | 경기 진행 화면, 최근 경기 결과, 일정 → [경기](02-match.md) |
| **리그** | 순위표, 기록 순위, 승강 플레이오프 신청 → [리그](03-league.md) |
| **구단** | 훈련소, 경기장, 홍보, 재정 → [구단 운영](04-club-management.md) |
| **선수** | 로스터, 라인업, 영입 → [선수 영입](05-player-recruitment.md) |
| **설정** | 토큰 경로, 환산 난이도, 알림, 애니메이션 |

💡 알림: 경기 가능, 시즌 종료, 승강 플레이오프 결과, 업그레이드 완료.

## 기술 스택

✅ **macOS 전용, Swift**로 만든다.

| 항목 | 선택 |
|---|---|
| 언어 | Swift 6 |
| UI | SwiftUI (`MenuBarExtra` 팝오버) + 필요한 곳만 AppKit (`NSStatusItem` 애니메이션) |
| 최소 버전 | 💡 macOS 14 (Sonoma) 이상. PokeTokenBar와 같음 |
| 빌드 | Swift Package Manager |
| 저장 | 💡 로컬 파일 (JSON 또는 SQLite). 서버 없음 |
| 배포 | 💡 GitHub Releases, 나중에 Homebrew cask |

💡 모듈 구조: 게임 로직은 UI와 분리해서 테스트하기 쉽게 만든다.

```
Sources/
  TokenBaseballCore/   게임 로직 (UI 의존 없음)
    Usage/             로컬 로그에서 토큰 사용량 읽기
    League/            리그, 일정, 순위, 승강
    Match/             투구 단위 경기 시뮬레이션
    World/             세계 시뮬레이션 (CPU 팀, 성장, 맞춰주기)
    Club/              시설, 홍보, 재정, 인지도
    Players/           선수 생성, 능력·잠재력, 영입
  TokenBaseball/       macOS 앱 (상단바, 팝오버, 설정)
Tests/
  TokenBaseballCoreTests/
```

- 경기 시뮬레이션은 시드를 넣으면 항상 같은 결과가 나오게 만들어 테스트한다.
- 💡 레포의 `.gitignore`는 지금 Node용이라 Swift/Xcode용으로 바꾼다.
