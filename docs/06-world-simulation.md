# 6. 세계 시뮬레이션 (CPU 팀)

Football Manager처럼 내 팀만이 아니라 **6개 리그의 모든 팀과 선수**가 함께 움직인다.
CPU 팀도 경기를 치르고, 선수가 성장하고 늙고, 시설을 짓고, 선수를 영입한다.

## 확정된 내용

- ✅ CPU 팀은 내 팀 수준에 적당히 맞춰 준다.
- ✅ 경기를 한 번 마칠 때마다 시뮬레이터가 돌아 CPU 팀의 실력 변화 등을 반영한다.
- ✅ 모든 리그의 모든 선수에게 능력과 잠재력이 있고, 잠재력까지 성장한다.
- ✅ 게임 시작 시점의 선수들(특히 내 시민 구단)은 잠재력이 높지 않다.

## 규모

💡 6개 리그 × 10팀 = **60팀**, 팀당 14~28명이면 선수는 **약 1,200명**이다. 경기 한 번마다 전부 계산해도 가벼운 양이다.

## 경기 한 번 뒤에 도는 시뮬레이션 (틱)

내가 **경기 시작**을 누르면 아래 순서로 세계가 한 라운드 진행된다.

1. **모든 리그의 같은 라운드 경기 진행**
   - 내 경기: 타석 단위 상세 시뮬레이션 → [경기](02-match.md#시뮬레이션)
   - 다른 경기 (30경기): 같은 엔진으로 돌리되 중계 텍스트는 만들지 않고 결과와 기록만 남긴다
   - 6개 리그가 같은 속도로 진행되어야 시즌이 동시에 끝나고 승강 플레이오프를 치를 수 있다
2. **모든 선수 성장·하락 반영** → 아래 [성장](#성장)
3. **부상 회복, 컨디션 변화**
4. **CPU 구단 운영**: 자금이 쌓이면 시설 업그레이드, 홍보, 로스터 정리
5. **맞춰주기 보정** → 아래 [CPU 팀 맞춰주기](#cpu-팀-맞춰주기)
6. **뉴스 생성**: 눈에 띄는 일을 홈 화면 뉴스 피드에 올린다
   - 예) "부산 시민 야구단 19세 투수 김○○, 이번 달 구속 급상승"
   - 예) "3부 아마추어 ○○팀, 실내 연습장 완공"

## 능력과 잠재력

FM의 CA/PA와 같은 개념이다.

| 값 | 범위 | 뜻 |
|---|---|---|
| **능력 (CA)** | 1~100 | 지금 실력. 세부 능력치(컨택, 파워, 구위 등)를 포지션별 가중치로 합친 종합 점수 |
| **잠재력 (PA)** | 1~100 | 도달할 수 있는 최대 능력. 선수가 생성될 때 정해진다 |

- 능력은 잠재력을 넘을 수 없다.
- 💡 잠재력은 기본적으로 고정이다. 드물게 **각성 이벤트**로 +3~8 오를 수 있다 (예: 시즌 MVP, 큰 경기 맹활약).
- 💡 잠재력은 숨겨져 있고, **스카우트 평가**(별 1~5개)로 대략만 보인다. 스카우트 시설 레벨이 높을수록 평가가 정확하다. 실제로는 별 4개라고 봤는데 크지 못하는 선수도 있다.
- 세부 능력치와의 관계는 → [선수 영입](05-player-recruitment.md#능력치)

## 성장

💡 경기 한 번(틱)마다 모든 선수에게 성장 포인트를 계산한다.

```
성장 포인트 = 기본값 × 나이 계수 × 잠재력 여유 × 훈련 계수 × 출전 계수
```

| 요소 | 값 (💡) |
|---|---|
| **나이 계수** | 22세 이하 ×1.5 · 23~26세 ×1.0 · 27~30세 ×0.4 · 31~33세 ×0 (유지) · 34세 이상 하락 |
| **잠재력 여유** | `(잠재력 − 능력) ÷ 잠재력`. 잠재력에 가까울수록 느려지고, 같아지면 멈춘다 |
| **훈련 계수** | 소속 팀 훈련소 레벨 배율 (×1.0~×2.5) → [구단 운영](04-club-management.md#훈련소) |
| **출전 계수** | 주전 ×1.2 · 교체 출전 ×1.0 · 미출전 ×0.6 |

- 성장 포인트가 쌓이면 세부 능력치가 오르고 능력(CA)이 다시 계산된다. 어떤 능력치가 오를지는 포지션과 팀 훈련 방침에 따라 정한다.
- 💡 기준: 20세, 능력 30, 잠재력 60인 선수가 주전으로 뛰면 **4~5시즌**에 잠재력 근처까지 간다.
- 💡 나이는 시즌이 끝날 때 1살 늘어난다 (1시즌 = 1년).
- 💡 하락: 34세 이상은 시즌마다 체력·주력부터 떨어진다. 은퇴는 나이와 능력 하락 폭으로 정한다.
- CPU 팀 선수도 똑같은 공식을 쓴다. CPU 팀 유망주도 크고, 베테랑은 늙는다.

## 시작 시점의 잠재력

✅ 게임을 시작할 때 잠재력이 높으면 이상하다. 동네 사회인 야구단에서 국가대표 재목이 나오지는 않는다.

💡 리그별로 **새로 생성되는 선수**의 잠재력 범위를 다르게 둔다.

| 리그 | 능력 | 잠재력 | 나이 |
|---|---|---|---|
| 6부 시민 아마추어 | 15~35 | 능력 + 0~10 (최대 45) | 20~45세 (직장인 위주) |
| 5부 시민 세미프로 | 25~45 | 능력 + 0~12 | |
| 4부 시민 프로 | 35~55 | 능력 + 0~15 | |
| 3부 아마추어 | 45~65 | 능력 + 0~20 | 대학·실업 선수 |
| 2부 세미프로 | 55~72 | 능력 + 0~20 | |
| 1부 프로 | 62~90 | 능력 + 0~15 | |

- **내 시작 로스터 14명**: 6부 기준으로 생성한다. 대부분 잠재력이 능력과 거의 같아서 크게 크지 않는다.
- 💡 **숨은 보석**: 낮은 확률로 6부에도 잠재력 55~65인 젊은 선수가 섞여 있다. 시작 로스터에는 💡 최대 1명만 넣고, 그마저도 별 2개 정도로 낮게 보인다.
- **높은 잠재력 유망주를 얻는 길**: 리그가 오를수록 입단 테스트와 스카우트에 좋은 선수가 온다. 유소년 야구 교실 같은 홍보도 유망주 후보를 늘린다. 3부부터는 신인 드래프트가 열린다 → [선수 영입](05-player-recruitment.md#영입-경로)

## CPU 팀 맞춰주기

✅ CPU 팀은 내 팀 수준에 적당히 맞춰 준다.

맞춰주기가 지나치면 내가 투자해도 상대도 같이 강해져서 성장하는 재미가 없다. 그래서 **리그별 강도 범위** 안에서만, **천천히** 따라온다.

### 리그별 팀 강도 범위

팀 강도 = 주전 라인업 + 선발 투수진의 평균 능력.

| 리그 | 팀 강도 범위 (💡) |
|---|---|
| 6부 시민 아마추어 | 20~40 |
| 5부 시민 세미프로 | 30~50 |
| 4부 시민 프로 | 40~60 |
| 3부 아마추어 | 50~70 |
| 2부 세미프로 | 60~80 |
| 1부 프로 | 70~92 |

### 보정 방법

💡 CPU 팀의 능력치를 바로 바꾸지 않고, **성장 속도와 영입**을 조절해서 자연스럽게 따라오게 한다.

1. 리그의 **목표 평균** = 내 팀 강도를 위 범위 안으로 자른 값
2. CPU 팀마다 목표에서 떨어진 정도를 정해 둔다. 강팀 2~3개(+5~+10), 중위권, 약팀 2~3개(−5~−10). 시즌마다 다시 정한다
3. CPU 팀이 목표보다 약하면 성장 속도 +10~20%, 오프시즌 영입에서 더 좋은 선수를 데려간다. 강하면 그 반대
4. **한 시즌에 따라올 수 있는 양을 제한**한다. 예) 리그 평균은 시즌당 최대 +3
5. 승격하면 새 리그는 원래 범위의 아래쪽에서 시작해, 처음 올라간 팀이 아주 불리하지 않게 한다

결과적으로:
- 열심히 투자하면 리그를 압도할 수 있다 (범위 상한과 시즌당 제한 때문에 CPU 팀이 다 따라오지 못한다).
- 투자를 안 해도 리그가 너무 쉬워지지는 않는다 (범위 하한).
- 리그 안에 강팀·약팀이 있어서 순위 싸움이 생긴다.

❓ 설정에 맞춰주기 강도(약하게 / 보통 / 강하게 / 끄기)를 둘지

## CPU 구단 운영

💡 CPU 구단도 내 팀과 같은 규칙으로 운영되지만, 돈은 토큰 대신 리그별 고정 수입으로 받는다.

| 항목 | CPU 팀 동작 |
|---|---|
| 자금 | 리그별 기본 수입 + 관중 수입 + 순위 상금 |
| 시설 | 자금이 모이면 훈련소 → 경기장 순으로 업그레이드 |
| 영입 | 오프시즌에 약한 포지션을 FA·드래프트로 채움 |
| 방출 | 로스터가 차면 능력이 가장 낮은 고령 선수부터 |
| 라인업 | 능력 순으로 자동 구성, 선발 투수 로테이션 |

💡 CPU 팀마다 **성향**을 둔다: 유망주 육성형, 베테랑 선호형, 투수력 중시형 등. 같은 리그 팀들의 색깔이 달라진다.
