# Token Baseball 기획 문서

AI 코딩 도구에서 쓴 토큰이 **구단 자금**이 되는 메뉴바 야구단 육성 게임.
시민 야구단으로 시작해 6부 리그의 최상위 프로 리그까지 올라가는 것이 목표다.
혼자 하는 오프라인 아케이드 게임이며 네트워크 기능은 없다. 상대 팀은 모두 AI다.

> 영감: [chattymin/PokeTokenBar](https://github.com/chattymin/PokeTokenBar) — 로컬 로그에서 토큰 사용량을 읽어 메뉴바의 포켓몬을 키우는 macOS 앱.

## 확정된 요구사항

1. 토큰 사용량이 구단 자금이 된다.
2. 구단 자금으로 훈련소 업그레이드, 경기장 업그레이드, 홍보 등을 하며 야구팀을 키운다.
3. 시민 야구단으로 시작하며, 시작할 때 팀 이름을 정한다.
4. 경기는 1시간마다 한 번, 직접 눌러서 진행한다.
5. 상단바(메뉴바)에는 선수들이 훈련하는 모습이 나온다.
6. 야구 규칙은 기본 규칙을 따르고, 리그 운영은 KBO 방식을 따른다.
7. 리그는 6부제다: 시민 아마추어 → 시민 세미프로 → 시민 프로 → 아마추어 → 세미프로 → 프로.
8. 인지도가 충분하면 승강 플레이오프를 신청할 수 있다.
9. 승강 플레이오프 진출 여부는 정규시즌이 모두 끝난 뒤 순위로 정한다.
10. 같은 리그의 모든 팀과 홈 2경기, 원정 2경기씩 치른다.
11. 혼자 하는 아케이드 게임이다 (네트워크 없음). 토큰 수를 가중치 없이 그대로 자금으로 쓴다.
12. CPU 팀은 내 팀 수준에 적당히 맞춰 준다.
13. 경기를 한 번 마칠 때마다 시뮬레이터가 돌아 CPU 팀의 실력 변화 등을 반영한다 (Football Manager 방식).
14. 모든 리그의 모든 선수에게 능력과 잠재력이 있고, 잠재력까지 성장한다.
15. 게임 시작 시점의 선수들은 잠재력이 높지 않다.
16. CPU 팀 맞춰주기 강도는 설정에서 고른다 (끄기 / 약하게 / 보통 / 강하게).
17. 상단바는 짧게: 훈련 애니메이션 + 숫자 하나. 구단 자금 / 오늘 사용량 / 다음 경기 중 하나를 설정에서 고른다.
18. 경기가 끝나면 상단바 설정과 상관없이 "경기 종료"를 표시한다.
19. 경기는 결과가 바로 나오지 않고, 실제 야구처럼 한 구 한 구 시뮬레이션이 돌아가는 실시간 중계로 진행된다. 배속과 건너뛰기는 없다.
20. 상대 팀은 모두 가상 구단이다. 1부 10팀은 KBO 구단의 연고지 + 애칭을 우리말로 옮긴 이름 (예: 광주 호랑이). 기업명·엠블럼·실제 선수 이름은 쓰지 않는다.
21. macOS 전용 앱으로, Swift로 만든다.
22. 설치 이전 사용량은 소급하지 않는다. 시작 자금은 ₩100,000.
23. 경기 기회는 최대 3경기까지 쌓인다.
24. 상위 리그 10위는 자동 강등, 9위는 승강 플레이오프.
25. 강등되면 다른 구단 오퍼가 몰려 선수를 뺏길 수 있다. 판 돈은 구단 자금에 들어온다.
26. 선수 연봉이 있고 시즌이 끝날 때만 오른다. 계약이 끝나면 선수가 떠나며, 떠날 선수를 미리 확인할 수 있다.
27. 파산 시스템: 파산하면 팀이 해체되고 새 팀을 키운다.
